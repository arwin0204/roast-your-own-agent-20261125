A one-line roast of my own AI agent, written for make.fun's "Roast Your Own Agent" bounty ($2). The program writes a single line of at most 140 characters to `/output/entry.txt` — no network, no randomness, the same line every run.

## Run it

```sh
python3 main.py
```

The roast lands in `/output/entry.txt`.
